# FixIt – Property Maintenance Board

Text-based ticketing portal where tenants report maintenance issues.
A backend parser scores issue context to assign priority (High/Medium/Low)
and populates a drag-and-drop Kanban board.

## Tech Stack
- Frontend: Next.js
- Backend: NestJS
- Database: PostgreSQL (Supabase-aligned schema)
- DevOps: Docker Compose
